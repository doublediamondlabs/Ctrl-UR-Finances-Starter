# Support

This experimental personal project is maintained as time permits. There is no
promised response schedule, paid support service, or commitment to add features.

For an ordinary bug, open a GitHub issue with the app, Windows and Python versions,
steps to reproduce, expected result, and exact error text with personal paths removed.
Use fictional examples. Do not attach workbooks, customer records, backup ZIPs,
financial information, access tokens, or unredacted screenshots.

Preserve on-screen edits after a failed save and keep recovery copies. Investigate
in a separate test installation. For security concerns follow SECURITY.md.
