# A five-minute fictional household

Use a fresh Starter in a separate disposable folder. Choose household name
**Example Household** and year **2026**. Leave optional modules off.
These invented figures demonstrate the interface, not financial guidance.

In Personal / Household, create these categories if missing and enter recorded expenses:

| Month | Category | Description | Amount |
|---|---|---|---:|
| September | Groceries | Example weekly shopping | 420 |
| September | Food - Misc | Example takeaway | 115 |
| September | Misc - Retail | Example supplies | 85 |
| September | Misc - Online | Example online purchase | 140 |
| October | Groceries | Example weekly shopping | 400 |
| October | Food - Misc | Example takeaway | 75 |
| October | Misc - Retail | Example supplies | 95 |
| October | Misc - Online | Example online purchase | 80 |

Open Year-end Summary → Spending Snapshot → Spending Mix. Compare September and
October, then select two categories. Search **Example takeaway** using Find That
Thing and open a result. Review the month reminders; an empty month is not reviewed.

Make a backup and inspect the reported file locations. This is a useful Windows
pilot before creating a separate household for real records. Do not add fictional
entries to an established installation unless you want them there.
