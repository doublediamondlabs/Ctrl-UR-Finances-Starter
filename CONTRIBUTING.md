# Contributing

Small, focused issues and pull requests are welcome. Discuss large features first;
maintainers may not have time to review or merge them.

Preserve offline use, compact navigation, optional modules, and separation of
program files from user data. Test with synthetic records in isolated folders,
never against real workbooks or shared data.

Follow docs/MAINTENANCE.md, retain lockfiles, and run `python tools/release.py` for
a release candidate. Explain the problem, change, verification, and any migration.
Avoid unrelated dependency upgrades. Contributions use the repository's MIT license.
