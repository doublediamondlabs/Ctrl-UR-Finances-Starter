CTRL UR FINANCES — v3.32.53-alpha.4
EXPERIMENTAL OFFLINE HOUSEHOLD STARTER

NEW INSTALLATION
Extract this entire Starter ZIP to a NEW folder. Run Start-App.bat with Python 3.10
or newer installed. No pip packages, online account or internet are needed to run
it. Enter your household name, starting year and an empty data folder. Begin in
Personal / Household. Optional Business, Inspections & Travel, Loan Tracking,
Family Repayments, Move Planner and RōM Travel Exchange start Off; enable them in Modules & appearance.

EXISTING SUPPORTED STARTER INSTALLATION
Use the separate Starter-Update ZIP. Back up first, use Exit Ctrl Ur Finances (or close the old command window),
close linked Excel workbooks, then run Apply-Update.bat and choose
the EXISTING Starter folder containing Start-App.bat. Reopen and confirm
3.32.53-alpha.4. Your entries, links, settings, logo and optional modules stay put.
Do not use a live Double Diamond Expense Book update on this Starter.

RECENT ADDITIONS
Spending Mix doughnuts with selectable categories and period comparisons; compact
summary controls; clearer Tax Preparation; optional RōM file exchange (Off by
default on upgrade too). The separate RōM application is not included or required.
Saved-destination reminders; printable Inspection Brief; optional VIN and ZIP;
multiple customers, phone numbers and emails; optional Paid By; dealer/private-sale
visit breakdowns; collapsible Business navigation; clearer Home review status;
compact Backup & Recovery and optional automatic backup retention.
Find That Thing, Year in the Rearview, configurable editions and pinned tools remain.

BACKUP RETENTION
Starts Off. Review the folder estimates, enable retention, then make a full backup.
Cleanup runs only after verification and only removes eligible unchanged history
captured in that ZIP. It keeps recent and spaced historical copies. Full recovery
ZIPs remain yours to manage. Older Starter updater sets without a completion marker
are left alone. Background folder scan has visible progress and a Cancel button.

DATA AND SHARING
User-Data, or your chosen external folder, contains the workbooks and settings.
data-location.json beside Start-App.bat points there. Keep one active installation;
independent copies do not synchronize. Close linked Excel workbooks before saving.
Share the ORIGINAL clean Starter ZIP, not your already-used application folder.
Create-Portable-Copy includes YOUR data and is for moving your own installation.

LIMITATIONS
Still experimental. Native Windows display, network-share operation and printed
pagination require a pilot. Bank import remains the existing supported format;
generic bank PDF/OCR import is not included. Move Planner compares monthly cash
needs and does not calculate a home purchase price. No private financial amounts,
workbooks, customer information, uploaded logos or photos are packaged.

QUIET DESKTOP SHORTCUT AND EXIT
After installation, run Install-Desktop-Shortcut.bat FROM YOUR INSTALLED STARTER
FOLDER on each computer. The shortcut opens silently and uses the two-diamond
icon. Do not create it from an update ZIP's payload folder. Use Exit Ctrl Ur
Finances at the top right or in the sidebar before updates. Save work in other
browser tabs first. Backup/scan operations must finish before Exit is accepted.
If using an older version, close its command window before installing the update.
Start-App-Diagnostics.bat remains available for visible startup diagnostics.
